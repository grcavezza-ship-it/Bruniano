# Bruniano

Sito web custom per Bruniano.

## Stack

- HTML5 semantico
- CSS moderno responsive
- JavaScript vanilla
- GitHub come repository/versionamento
- Struttura predisposta per Cloudflare Pages
- Area amministrativa Team prevista in una fase successiva

## Obiettivi

- sito istituzionale veloce e responsive
- identità visiva coerente con il logo Bruniano
- CTA WhatsApp per richieste di prenotazione
- Team gestibile da pannello senza modificare il codice
- nessuna raccolta di dati sanitari nel sito

## Stato

V1: struttura e homepage iniziale. I contenuti definitivi, immagini, video, numero WhatsApp, contatti e dati del team verranno inseriti dopo la validazione con lo studio.
